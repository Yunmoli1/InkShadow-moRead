/goal 开发一个名为“墨读 (MoRead)”的全栈知识管理应用。定位为“个人本地知识库”，仅供个人学习研究。项目核心采用“工具调度”架构，通过调度专业开源工具，实现对**小说、图片、音频、视频及完整网页**的获取、管理与预览。

## 🏗️ 一、项目结构与技术栈
- **后端**：`/backend`，Python 3.11+，**FastAPI** + **SQLAlchemy 2.0** (异步) + **SQLite** (aiosqlite)
- **前端**：`/frontend`，**React 18** + **Vite** + **TypeScript**，Zustand 管理状态
- **UI框架**：**Tailwind CSS v4** + **shadcn/ui** (使用 `pnpm dlx shadcn@canary init` 初始化)
- **PWA**：**vite-plugin-pwa**，支持离线访问和桌面安装
- **工具目录**：`/tools`，存放封装外部工具的脚本

## 🛠️ 二、工具调度架构（核心）
**应用不内置爬虫**，通过调度外部专业工具实现内容获取：

1. **多媒体全能下载器**：`abx-dl`、`DXC`、`vget` — 自动检测并下载URL中的HTML/图片/视频/音频
2. **视频/音频专项**：`yt-dlp`、`pull-vids`、`you-get` — 支持1000+网站
3. **图片专项**：`gallery-dl`、`image-harvest` — 支持1400+网站
4. **网页归档**：`ArchiveBox` — 完整保存网页为HTML/PDF/PNG截图
5. **小说专项**：`lncrawl`、`FictionDown`、`So Novel`、`novel-downloader`

**工具封装要求**：
- 后端提供统一适配器，使用 `asyncio.create_subprocess_exec` 非阻塞调用
- 实时捕获 stdout/stderr，解析进度信息并通过 SSE 推送
- 工具未安装时返回明确状态，应用不崩溃
- 支持工具安装状态检测和版本校验

## 📡 三、后端 API 规范
1. `GET /api/tools` — 获取已安装工具列表及状态
2. `POST /api/tools/{tool_name}/search` — 调用工具搜索
3. `POST /api/tools/{tool_name}/download` — 调用工具下载（返回 task_id）
4. `GET /api/tasks` — 获取所有下载任务列表（支持分页）
5. `GET /api/tasks/{task_id}/status` — 获取任务状态（SSE 流式推送进度）
6. `POST /api/tasks/{task_id}/pause` — 暂停下载任务
7. `POST /api/tasks/{task_id}/resume` — 恢复下载任务（支持断点续传）
8. `DELETE /api/tasks/{task_id}` — 取消并删除任务
9. `GET /api/novels` — 获取书架列表（分页、搜索、筛选）
10. `GET /api/novels/{id}` — 获取小说详情
11. `GET /api/novels/{id}/chapters` — 获取章节列表（支持虚拟滚动分页）
12. `GET /api/novels/{id}/chapters/{cid}/content` — 获取章节内容
13. `DELETE /api/novels/{id}` — 删除小说
14. `PATCH /api/novels/{id}/progress` — 更新阅读进度
15. `POST /api/novels/{id}/notes` — 保存读书笔记
16. `GET /api/novels/stats` — 获取阅读统计汇总
17. `POST /api/novels/{id}/ai-summary` — AI 总结章节摘要
18. `POST /api/novels/import` — 批量导入本地小说文件（TXT/EPUB）
19. `GET /api/media` — 获取多媒体资源列表（按类型筛选）
20. `GET /api/media/{id}` — 获取多媒体资源详情（含预览URL）
21. `DELETE /api/media/{id}` — 删除多媒体资源
22. `POST /api/media/batch-import` — 批量导入本地多媒体文件

## 🎨 四、UI/UX 与设计系统

### 1. 设计哲学
- **“内容优先，沉浸无扰”**：UI 是内容的画框，而非主角。所有视觉元素旨在增强而非分散阅读注意力。
- **“细腻与克制”**：交互反馈应温和、自然，避免夸张动画；色彩使用应克制，营造平静、专注的氛围。

### 2. 设计令牌（Design Tokens）
- **色彩系统（深色/浅色双主题）**：
  - **浅色主题**：背景 `#fdf6e3`（羊皮纸），卡片 `#ffffff`，正文 `#2c2c2c`，辅助文字 `#6b6b6b`，强调色 `#c0392b`（朱砂红）。
  - **深色主题**：背景 `#1a1a2e`，卡片 `#16213e`，正文 `#e8e6e3`，辅助文字 `#a0a0a0`，强调色 `#e94560`。
- **字体系统**：
  - **正文字体**：`"Literata", "Noto Serif SC", serif`（衬线，提升纸质阅读感）。
  - **标题/UI字体**：`"Inter", "PingFang SC", sans-serif`（无衬线，保证清晰度）。
- **间距与圆角**：遵循 **8px 网格系统**；卡片圆角 `12px`，按钮圆角 `8px`，弹窗圆角 `16px`。
- **阴影层级**：`sm` (轻微悬浮) → `md` (卡片) → `lg` (弹窗/下拉菜单) → `xl` (全局遮罩)。

### 3. 页面级布局规范
- **全局框架**：顶部导航栏（56px）+ 左侧边栏（240px，可折叠）+ 右侧主内容区。
- **阅读器**：**内容居中**，最大宽度 `860px`；行高 `1.8`；段落间距 `1.5rem`；首行缩进 `2em`。
- **书架/资源库**：卡片网格（桌面 `4-6` 列，平板 `3` 列，移动 `2` 列），卡片悬停微抬升动效。

### 4. 交互与动效规范
- **翻页动画**：模拟纸质书翻页（卷曲或滑动），使用 `framer-motion` 实现。
- **工具唤出**：鼠标悬停/触摸屏幕边缘时，工具栏从底部或侧边平滑滑入。
- **反馈**：所有点击操作（如添加书签、切换主题）需有**触感反馈**（微震动或波纹效果）。
- **加载状态**：使用**骨架屏（Skeleton）** 占位，而非传统 Spin，减少用户等待焦虑。

### 5. 设计交付与执行
- **Figma 先行**：Agent 需在编码前，在 `.docs/` 目录下生成一份 **Figma 设计规范文档**（用 Markdown 描述，非必须要求 Figma 文件），作为后续开发的唯一视觉标准。
- **shadcn/ui 定制**：使用 shadcn/ui 时，需通过 `globals.css` **完全覆盖**其默认主题，以匹配上述设计令牌。
- **移动端适配**：触控区域不小于 `44px`，支持手势（左右滑动翻页、双指缩放字体）。

## 📱 五、前端功能模块
1. **万能抓取页**：输入任意URL，选择内容类型（自动识别/图片/视频/音频/完整网页/小说），一键抓取，实时显示进度
2. **任务中心**：统一管理所有下载任务（排队中/进行中/已完成/失败），支持暂停/恢复/取消
3. **资源库**：统一展示小说、图片、视频、音频，按类型筛选，支持搜索
4. **多媒体预览**：视频/音频内置播放器，图片画廊模式浏览
5. **书架管理**：网格展示小说，支持搜索、筛选与删除
6. **沉浸式阅读器**：滚动/分页双模式，字体/主题调节，AI摘要侧边栏
7. **读书笔记**：划选添加笔记，按章节筛选，导出Markdown
8. **阅读统计**：阅读时长、已读章节、年度报告
9. **工具箱**：展示所有工具及其安装状态
10. **本地备份与恢复**：导出/导入加密 `.json` 备份
11. **键盘快捷键**：Space翻页、Ctrl+Z撤销、Ctrl+S保存笔记、Ctrl+K全局搜索
12. **TTS语音朗读**：Web Speech API，可调节语速和音调
13. **PWA支持**：可安装为桌面/手机应用，支持离线阅读

## 📱 六、多端适配要求
- **响应式设计**：Mobile-First，桌面多列网格+侧边栏，移动单列+触控手势翻页
- **性能优化**：章节列表使用 `react-window` 虚拟滚动；大文件解析使用 Web Worker
- **微交互动效**：平滑翻页动画、细腻过渡效果

## 🔒 七、安全、隐私与性能
- **隐私**：所有数据仅本地存储，绝不联网上传
- **AI调用**：默认使用本地模型（Ollama/Llama 3），用户可配置外部API Key
- **文件存储**：设置存储配额上限，提供清理策略
- **错误处理**：网络异常、工具调用失败时应用不崩溃，有友好提示
- **部署**：`pnpm run build` + `uvicorn` + `docker-compose.yml` 一键启动

## 📦 八、外部工具安装指引（README 提供）
- **lncrawl**：`pip install -U lightnovel-crawler`
- **yt-dlp**：`pip install yt-dlp`
- **gallery-dl**：`pip install gallery-dl`
- **you-get**：`pip install you-get`
- **abx-dl**：`pip install abx-dl`
- **ArchiveBox**：`docker run -v $PWD/data:/data archivebox/archivebox`
- **FictionDown / So Novel**：从 GitHub Releases 下载

## ✅ 九、验收标准
1. 后端所有 API 通过 `/docs` 测试通过
2. 前端完整走通“万能抓取 → 任务中心 → 资源库 → 预览”流程
3. 至少一个多媒体工具（yt-dlp 或 gallery-dl）成功调用并下载内容
4. 至少一个小说工具（lncrawl）成功调用并下载完整小说（50+ 章节）
5. 下载任务支持暂停/恢复（断点续传）
6. SSE 进度推送实时更新，连接断线自动重连
7. 1000+ 章节列表滚动流畅（虚拟滚动验证）
8. 大文件（>10MB）解析不阻塞 UI（Web Worker 验证）
9. 界面美观舒适，阅读体验流畅，交互动效细腻
10. 模拟网络异常或工具调用失败时，应用不崩溃且有友好提示
11. 应用在 Chrome/Firefox/Safari 及移动端表现正常
12. PWA 可成功安装，离线访问已缓存内容
13. 项目通过 `pnpm run build` 与 `docker-compose up` 成功运行
