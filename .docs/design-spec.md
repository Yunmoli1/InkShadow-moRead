# 墨读 MoRead — 设计规范文档（Design Spec）

> 本文档是墨读前端开发的**唯一视觉标准**（Figma 规范的 Markdown 形式）。
> 所有页面、组件、动效实现必须与本文档保持一致；修改设计需先修改本文档。

版本：v1.0 ｜ 日期：2026-09-07 ｜ 状态：定稿

---

## 1. 设计哲学

- **内容优先，沉浸无扰**：UI 是内容的画框，而非主角。阅读器中一切装饰让位于文字。
- **细腻与克制**：交互反馈温和自然（150–300ms、小位移、低饱和强调色），避免夸张动画。
- **纸墨意象**：浅色主题取"羊皮纸 + 朱砂批注"意象，深色主题取"夜读灯下"意象。

## 2. 设计令牌（Design Tokens）

> 实现位置：`frontend/src/globals.css` 的 `@theme` 与 CSS 变量（`:root` / `.dark`）。
> shadcn/ui 默认主题通过同一组变量**完全覆盖**。

### 2.2 字体

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-serif` | `"Literata", "Noto Serif SC", "Source Han Serif SC", serif` | 正文/阅读器 |
| `--font-sans` | `"Inter", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif` | 标题/UI |

加载方式：Google Fonts（Literata、Inter、Noto Serif SC）+ `font-display: swap`；
PWA 离线时回退系统衬线字体。阅读器正文字号默认 `18px`，可调 14–28px。

### 2.3 间距 / 圆角 / 阴影

- **间距**：8px 网格。令牌 `--spacing-*`：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- **圆角**：卡片 `12px`（`--radius-xl`）；按钮/输入框 `8px`（`--radius-lg`）；弹窗 `16px`（`--radius-2xl`）；小徽标 `6px`。
- **阴影**：
  - `shadow-sm`：`0 1px 2px rgba(0,0,0,.06)` 轻微悬浮（悬停前卡片）
  - `shadow-md`：`0 4px 12px rgba(0,0,0,.08)` 卡片默认/悬停微抬升
  - `shadow-lg`：`0 12px 32px rgba(0,0,0,.14)` 弹窗/下拉菜单
  - `shadow-xl`：`0 24px 64px rgba(0,0,0,.24)` 全局遮罩/命令面板

## 3. 布局系统

### 3.1 全局框架（App Shell）

```
┌──────────────────────────────────────────────┐
│ TopBar 56px：Logo · 全局搜索(Ctrl+K) · 主题切换 │
├──────────┬───────────────────────────────────┤
│ Sidebar  │  Main Content（router-view）        │
│ 240px    │  padding: 24px（移动端 16px）        │
│ 可折叠    │  max-width: 1440px 居中             │
│ 72px     │                                    │
└──────────┴───────────────────────────────────┘
```

- 侧边栏导航项：抓取 / 任务 / 资源库 / 书架 / 统计 / 工具箱 / 设置，高 40px，激活态左侧 3px 朱砂条。
- 移动端（<768px）：侧边栏收起为抽屉，底部无 Tab（保持内容区最大），触控目标 ≥44px。

### 3.2 阅读器（沉浸式）

- 内容居中 `max-width: 860px`；行高 `1.8`；段间距 `1.5rem`；首行缩进 `2em`。
- 顶部工具条与底部进度条**悬停/滚动时自动隐藏**（idle 3s 淡出）。
- 双模式：**滚动模式**（默认）与**分页模式**（framer-motion 翻页）。
- 右侧 AI 摘要侧边栏 320px，可收起；移动端为底部抽屉。

### 3.3 书架 / 资源库网格

- 桌面 ≥1280px：6 列；1024–1279px：5 列；768–1023px：3 列；<768px：2 列。
- 卡片比例：小说封面 3:4，媒体缩略图 16:9。
- 悬停：`translateY(-4px)` + `shadow-md→lg`，200ms ease-out；触屏设备取消悬停。

## 4. 组件规范

- **按钮**：高 40px（默认）/ 32px（sm）/ 44px（触控 lg）；圆角 8px；主按钮朱砂底白字，ghost 按钮透明底。
- **卡片**：圆角 12px，1px border + shadow-md。
- **弹窗/对话框**：圆角 16px，shadow-lg，遮罩 `rgba(0,0,0,.4)` + backdrop-blur(2px)。
- **骨架屏（Skeleton）**：所有列表/详情加载态一律用骨架屏（`--muted` 色块 + 1.5s shimmer），禁止传统 Spin。
- **进度条**：高 4px 圆角，朱砂色；任务卡片中附带百分比数字与速度文本。
- **Toast**：右下角堆叠，圆角 12px，自动消失 4s，含成功/错误/信息三态。
- **工具状态徽标**：`已安装 v<ver>`（success 点）/ `未安装`（warning 点）/ `检测中`（muted 点）。

## 5. 交互与动效

| 场景 | 规范 |
| --- | --- |
| 翻页动画 | 分页模式：纸质书滑动+轻微卷曲（framer-motion `rotateY` + 阴影渐变），280ms |
| 触感反馈 | 所有点击（书签/主题切换/按钮）：波纹 ripple 300ms + `navigator.vibrate(10)`（移动端） |
| 工具唤出 | 阅读器底部工具栏：屏幕下/侧边缘 hover 或触摸滑入，`y: 100% → 0`，220ms |
| 页面切换 | 内容区淡入+4px 上移，200ms |
| SSE 进度 | 任务卡片进度条平滑过渡；数字滚动更新 |
| 断线重连 | SSE 断开后指数退避重连（1s→2s→4s→…上限 30s），顶栏显示"重连中"黄点 |

## 8. 移动端与可访问性

- Mobile-First 断点：`sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536`。
- 手势：阅读器分页模式支持左右滑动翻页；双指捏合调节字号（44–448px 触区）。
- 触控目标 ≥ 44×44px。
- 对比度：正文与背景对比度 ≥ 7:1，辅助文字 ≥ 4.5:1。
- 焦点可见：`:focus-visible` 显示 2px 朱砂 ring。
